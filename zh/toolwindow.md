# 工具窗口

> [English](../toolwindow.md)

**Dagger Graph** 工具窗口（右侧边栏）包含图画布、组件选择器和工具栏。

## 组件选择器

两级下拉：先选**模块桶**，再选桶内的**组件**。列表覆盖项目里所有根 `@Component`：源码组件（纯 Dagger）和 Hilt 生成组件。`@Subcomponent` 不在列表里——它们出现在父组件的图内部。

- 两个弹层都是平台内置 chooser：输入即过滤（驼峰、子串），长模块名会剥掉公共包前缀显示。
- 每个组件条目带归属 tooltip（例如定制该 Hilt 测试组件的测试类）。
- 匹配**当前构建变体**的条目标记 `*`。在 IDE 的 Build Variants 面板切换变体后标记会更新（选择器每次打开时刷新）。
- 同名组件依次用变体后缀（Hilt 多变体工程）、包名后缀、模块后缀区分。
- Android 工程中每个模块遵循各自选中的变体：app 模块和库模块可以跟随不同的变体。
- 当选中的组件属于**与 IDE 当前变体不同**的变体时，画布底部会显示可关闭的提示条——源码导航按当前变体解析（见[已知限制](limitations.md)）。

## 工具栏

视图与范围开关位于工具栏末尾的 **Options（齿轮）菜单**中。

| 按钮 | 作用 |
|---|---|
| **刷新** | 失效当前组件的缓存图并重新加载。 |
| **放大 / 缩小** | 以视口中心缩放（1.2× 步进）。也支持 Ctrl/Cmd + 滚轮，或触控板捏合。 |
| **适应窗口** | 把整图缩放进视口，并重新启用窗口缩放时的自动适配。 |
| **实际大小 (1:1)** | 缩放到屏幕像素级。 |
| **定位** | 在当前图的所有节点上打开快速搜索弹窗。支持驼峰、子串和大小写不敏感匹配；组件排在最前。回车/双击居中该节点并闪烁提示。 |
| **强制刷新** | 丢弃**所有**图缓存（含 PSI 缓存），探测 IDE 索引漏掉的 Hilt 产物并补索引，重新枚举根组件并重新加载。 |
| **窗口**（开关） | 把工具窗口移入浮动窗口——大图和多显示器场景好用。再次点击 dock 回去。不持久化。 |

工具栏末尾 **Options（齿轮）菜单**里的开关：

- **包含测试模块**（开关，默认关）——同时列出 unit-test / instrumented-test 组件；它们的图在所属模块的测试类路径内解析。按项目持久化。
- **内联**（开关，默认开）——内联 `@Binds` 委托：纯委托绑定不画成节点，边直接路由到最终提供方，并用双尖括号（»）标记。按项目持久化。
- **导航后聚焦**（开关，默认开）——源码 → 图导航命中节点后直接打开它的出入边聚焦视图；关闭时改为在完整图中 1:1 居中该节点。按项目持久化。
- **折行**（开关，默认关）——把过宽的图切成堆叠的多行（目标宽高比 ≈ 1.6）。小图永不折行。按项目持久化。
- **端口序**（默认**允许重排**）——决定节点依赖请求端口的行序。**允许重排**时布局引擎可重排节点内端口以减少交叉；**声明序**保持源码顺序。端口仍位于节点标题下方。按项目持久化。
- **Tooltip** 子菜单——**边预览**（默认开）：悬停边显示完全在屏幕外的端点；内联 `@Binds` 的边展开为 接口 → 实现。**组件 tooltip**（默认开）：悬停组件容器空白处显示组件路径。均按项目持久化。
- **帮助**（菜单最底部）——在浏览器中打开 [Squire 文档](https://xnchung.github.io/squire_docs/zh/)。

## 所有路径

在非根节点上右键，选择 **显示我的所有路径**，底部打开 **All paths of {node}** 面板；拖动面板上方的分隔条可上下调整高度。路径在后台枚举（最短优先，上限 200 条；达到上限时显示截断提示），搜索过程中流式追加到列表。列表条目带 1 基编号，条目之间有一条细的主题色分隔线。选中一条路径后其边以琥珀色永久高亮，与蓝色悬停高亮互不冲突。关闭面板、隐藏工具窗口或任何图重建（刷新、切换内联/折行/端口序、切换组件）都会取消搜索并清除高亮。

## 聚焦视图

在任意节点（包括根组件节点）上右键，选择 **只显示我的出入边**：画布切换成聚焦视图——只保留该节点以及所有进入/离开它的可见边，紧凑重排后以 **1:1** 展示，并把该节点居中。`@Binds` 委托保持内联，点击边仍会跳到 `@Binds` 方法。

这个视图是临时的：工具栏左上角的 **← 返回全图** 按钮（或 **Esc**）会立即切回完整图，并恢复进入前的缩放和滚动位置——不重建图、不重新布局。聚焦期间节点右键菜单和“悬停节点联动高亮出入边”关闭；边悬停高亮、tooltip、点击导航、**定位**、缩放/平移、**适应窗口**、**实际大小** 和双击边定位端点仍然可用。进入时会关闭 **所有路径** 面板。

刷新、切换组件或修改布局开关会退出聚焦视图并重新加载完整图；隐藏再显示工具窗口则保留聚焦视图。从源码跳图（行槽导航）遵循 **导航后聚焦**：开启（默认）时直接打开命中节点的聚焦视图并替换已有聚焦视图；关闭时先回到完整图并在其中居中节点。

## 进度与取消

建图完全在后台进行，分阶段进度：**解析（~70%）→ 布局（~25%）→ 渲染（~5%）**。进度分母由同一组件上一次构建估算，所以重复加载时百分比最准。

选择另一个组件（或刷新）会取消进行中的构建。超大图的取消是协作式的，生效可能需要片刻。

## 刷新时的视图状态保持

刷新或强制刷新**同一个**组件会保留你的缩放级别和视口锚点——画面停留在原处，而不是跳回适应窗口。布局也会以上一次坐标为种子，你正在看的节点保持在原位。

## 空状态

如果项目里没有 `@Component`（或还没发现），窗口显示 "No Dagger @Component found in project"。两个良性原因：

- **刚装好插件**：IDE 还在构建 Squire 的绑定索引——一次性重建索引完成前窗口保持空白。等索引进度条走完。
- **从未构建过的 Hilt 项目**：先跑一次 KSP/KAPT（或构建）。

工具窗口在空白状态下重新可见时，Squire 会自动执行一次强制刷新，以收录新索引或新构建的产物。
